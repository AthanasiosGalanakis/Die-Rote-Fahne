How do I get a token?
  1. On GitHub open Settings → Developer settings → Personal access tokens → Fine-grained tokens and choose Generate new token.
  2. Under Repository access pick Only select repositories and choose this game's repository.
  3. Under Permissions set Contents to Read and write and Actions to Read-only.
  4. Generate it and paste it above. It is kept only in this browser.
